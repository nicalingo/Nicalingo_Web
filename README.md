# NicaLingo — Landing Page

Landing page estática pensada para GitHub Pages.

## Estructura

- `index.html` — contenido y estructura.
- `styles.css` — identidad visual, responsive y animaciones.
- `script.js` — reveal on scroll, parallax y microinteracciones.
- `assets/nicalingo-logo.png` — logo preparado con fondo transparente.
- `fonts/` — coloca aquí los archivos de las tipografías de marca.

## Tipografías

La página está preparada para:
- `Bernoru` → títulos y textos grandes.
- `Basma` → textos pequeños, navegación y párrafos.

Coloca los archivos como:
- `fonts/Bernoru-Basma.woff2`
- `fonts/Basma.woff2`

## Publicar en GitHub Pages

1. Crea un repositorio.
2. Sube todos los archivos conservando las carpetas.
3. Ve a Settings → Pages.
4. Selecciona `Deploy from a branch`.
5. Elige `main` y `/root`.
6. Guarda y espera a que GitHub publique la página.
